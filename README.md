# 📊 Sistem Pengelolaan Data (CRUD) - Tugas Pemrograman Web (Pertemuan 8)

Repository ini berisi *source code* untuk tugas mata kuliah Pemrograman Web pada pertemuan kedelapan. Proyek ini berfokus pada implementasi operasi dasar **CRUD** (*Create, Read, Update, Delete*) berbasis web untuk mengelola data secara dinamis dan terstruktur.

## 📝 Deskripsi Proyek

Proyek ini merancang antarmuka dan menerapkan logika sistem untuk menangani alur pengelolaan data secara *real-time*. Pengguna dapat menambahkan data baru melalui formulir, melihat daftar data tersimpan dalam bentuk tabel atau kartu yang rapi, melakukan pembaruan (edit) informasi data, serta menghapus catatan data yang tidak lagi diperlukan.

## ✨ Fitur Utama

* **Create (Tambah Data):** Formulir interaktif dengan validasi input untuk memasukkan data baru ke dalam sistem.
* **Read (Tampilkan Data):** Menyajikan seluruh daftar data tersimpan secara terstruktur dan mudah dibaca.
* **Update (Ubah Data):** Fitur pengeditan data secara langsung untuk memperbarui informasi yang sudah ada.
* **Delete (Hapus Data):** Fitur untuk menghapus data tertentu dari sistem dengan opsi konfirmasi pemusnahan data.
* **Responsive UI:** Tampilan antarmuka yang adaptif untuk berbagai ukuran layar (desktop & mobile).

## 🛠️ Teknologi yang Digunakan

* **HTML5:** Struktur halaman dan elemen formulir.
* **CSS3 / SCSS:** Tata letak responsif, *styling* tabel, serta kustomisasi komponen UI.
* **JavaScript (ES6+):** Logika manipulasi data (*DOM manipulation*, *array operations*, atau *LocalStorage*).

## 🚀 Cara Menjalankan Proyek

1. *Clone* repositori ini ke komputer Anda:
   ```bash
   git clone https://github.com/ValdoMilo/TugasPemrogramanWeb-Pertemuan8-CRUD.git
   ```

2. Buka folder proyek di editor kode (seperti **Visual Studio Code**).

3. Jalankan aplikasi:
   * Klik kanan pada file `index.html`.
   * Pilih **Open with Live Server** (atau buka file `index.html` langsung melalui *browser* Anda).
